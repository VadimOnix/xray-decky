Everything a proxy client should do

  • One-paste import

    Paste any vless://, vmess://, trojan:// or ss:// link, a subscription URL, its base64 body — or a whole sing-box JSON config.

  • Subscriptions & server list

    Multi-server subscriptions with quota & expiry, editable names, manual and scheduled auto-refresh. Manually added servers always survive a refresh.

  • Latency testing

    Ping every server concurrently, see results in the list, switch with one tap — a live connection reconnects through the new server automatically.

  • Live traffic stats

    Real up/down speed and session totals from xray's stats API — in the Quick Access card and as a live graph in the admin panel.

  • TUN mode

    Routes all system traffic through the proxy — the only reliable way in Gaming Mode, where Steam ignores SOCKS settings. Survives suspend/resume.

  • Kill switch that cleans up

    Blocks traffic if the proxy drops — and reliably removes its firewall rules afterwards. A recovery script ships with the plugin, just in case.

  • Web admin panel

    Scan a QR from the Deck and manage everything from your phone: servers, import/export, options, updates. Token-guarded, rate-limited, with a LAN on/off switch.

  • Resilient by design

    Process supervisor restarts a crashed core in seconds, routes are repaired after suspend, versions are pinned — and everything is covered by 185 backend tests.

The Quick Access Menu is for playing.
The panel is for managing.

The QAM stays minimal: connect, pick a server, watch the speed. For everything else there's a Steam-styled web admin panel served by the plugin itself over HTTPS:

  • Dashboard with live status and a two-minute speed graph
  • Server list sorted by latency, with protocol and core badges
  • Subscription bar: refresh, rename, auto-refresh schedule, quota & expiry
  • Import anything · export every server as share links or a subscription
  • Update checker for the plugin and its cores — telemetry-free
  • English & Russian, switchable on the fly

Security model: per-install token (QR-paired), constant-time comparison, failed-auth rate limiting, credentials never shown in list views — and a QAM toggle to restrict the whole thing to the Deck only.

Installation

Prerequisites

  • Steam Deck with Decky Loader installed
  • ALPHA not yet validated on real hardware — expect rough edges and please report issues

Option 1 · Plugin Store

  1. Open Decky Loader settings (Quick Access → ⋯)
  2. Navigate to Plugin Store
  3. Search for “Xray Decky”
  4. Click Install

Option 2 · Desktop Mode

  1. Switch to Desktop Mode
  2. Download Install‑Xray‑Decky.desktop
  3. Properties → Permissions → “Is executable”
  4. Double-click to run the installer

Option 3 · Manual

  1. Grab the latest release zip
  2. Decky → Settings → Developer → Install Plugin from URL
  3. Paste the zip URL

Why TUN mode?

In Gaming Mode Steam ignores system SOCKS settings — games and system services bypass the proxy. TUN creates a virtual network interface that routes everything, so it's the mode you actually want. Just flip the toggle; the plugin handles routes and cleanup itself.

From zero to proxied in three steps

1

Import

Paste a share link or subscription URL in the QAM — or scan the QR and paste it from your phone. Every server in a subscription is stored.

2

Connect

One toggle. Live status and speed right in the Quick Access card. Pick a different server any time — reconnection is automatic.

3

Go system-wide

Enable TUN mode for Gaming Mode coverage, add the kill switch if you want strict leak protection, and manage the rest from the web panel.

Troubleshooting

Connection fails
  • Verify the share link or subscription URL is valid — invalid links are rejected before they can break a working config
  • Check network connectivity on your Steam Deck
  • Ping the servers from the list and try the fastest one
TUN mode not working
  • Ensure the plugin has the required privileges (see the repository's INSTALLATION.md)
  • Re-toggle TUN after a system update — SteamOS updates can wipe permissions
Kill switch is blocking traffic
  • Reconnect the proxy — the kill switch releases automatically
  • Or press Unblock traffic in the plugin / admin panel
  • Worst case: scripts/recover.sh ships with the plugin and restores networking unconditionally
Can't open the admin panel from my phone
  • Check the Allow LAN access toggle in the QAM options — in Deck-only mode the panel is deliberately unreachable from other devices
  • Both devices must be on the same network; accept the self-signed certificate warning
  • The QR embeds a per-install token — pair by scanning, don't retype the URL
xray-core binary missing
  • The plugin re-downloads its pinned core automatically on next start
  • Offline? Download from Xray-core releases into backend/out/
